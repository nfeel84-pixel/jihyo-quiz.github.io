🚀 3일차: 1차 컴파일! 3칸 기차 조립 완료하기

💡 꼬리칸을 달면 단어가 완성된다!

지효야, 1일차의 머리칸(첫 자음)과 2일차의 배터리(모음) 뒤에 꼬리칸(끝 자음)을 하나 더 붙이면 드디어 완벽한 단어 기차가 만들어져.
영어 기차는 왼쪽에서 오른쪽으로 쭉~ 이어지지만, 빨리 읽으면 이 꼬리칸 소리가 마치 한글의 '받침'처럼 쏙! 들어가게 돼.

알고리즘 실행 규칙:
1. 앞에서부터 순서대로 머리칸 + 배터리 + 꼬리칸 소리를 확인한다.
2. 소리를 빠르게 이어 붙인다. (꼬리칸을 한글 받침처럼 생각하면 아주 쉬워!)

⚡ A 배터리 기차 (애)
Bat뱃 (방망이/박쥐)
⚙️ 기차 조립 공식
B(ㅂ) + a(애) + t(ㅌ/받침ㅅ)
➔ ㅂ+애+ㅅ = 뱃!
Map맵 (지도)
⚙️ 기차 조립 공식
M(ㅁ) + a(애) + p(ㅍ/받침ㅂ)
➔ ㅁ+애+ㅂ = 맵!
Tap탭 (톡톡 치다)
⚙️ 기차 조립 공식
T(ㅌ) + a(애) + p(ㅍ/받침ㅂ)
➔ ㅌ+애+ㅂ = 탭!
⚡ E 배터리 기차 (에)
Pen펜
⚙️ 기차 조립 공식
P(ㅍ) + e(에) + n(ㄴ)
➔ ㅍ+에+ㄴ = 펜!
Bed베드 (침대)
⚙️ 기차 조립 공식
B(ㅂ) + e(에) + d(ㄷ)
➔ ㅂ+에+ㄷ = 베드! (끝소리 d는 살짝 '드'로 읽어줘요)
Pet펫 (반려동물)
⚙️ 기차 조립 공식
P(ㅍ) + e(에) + t(ㅌ/받침ㅅ)
➔ ㅍ+에+ㅅ = 펫!
⚡ I 배터리 기차 (이)
Pig피그 (돼지)
⚙️ 기차 조립 공식
P(ㅍ) + i(이) + g(ㄱ)
➔ ㅍ+이+ㄱ = 피그!
Dip딥 (살짝 담그다)
⚙️ 기차 조립 공식
D(ㄷ) + i(이) + p(ㅍ/받침ㅂ)
➔ ㄷ+이+ㅂ = 딥!
Sit싯 (앉다)
⚙️ 기차 조립 공식
S(ㅅ) + i(이) + t(ㅌ/받침ㅅ)
➔ ㅅ+이+ㅅ = 싯!
⚡ O 배터리 기차 (아/오)
Dog도그 (개)
⚙️ 기차 조립 공식
D(ㄷ) + o(오) + g(ㄱ)
➔ ㄷ+오+ㄱ = 도그!
Pot팟 (냄비)
⚙️ 기차 조립 공식
P(ㅍ) + o(아) + t(ㅌ/받침ㅅ)
➔ ㅍ+아+ㅅ = 팟!
Top탑 (팽이)
⚙️ 기차 조립 공식
T(ㅌ) + o(아) + p(ㅍ/받침ㅂ)
➔ ㅌ+아+ㅂ = 탑!
⚡ U 배터리 기차 (어)
Sun썬 (태양)
⚙️ 기차 조립 공식
S(ㅅ) + u(어) + n(ㄴ)
➔ ㅅ+어+ㄴ = 썬!
Mud머드 (진흙)
⚙️ 기차 조립 공식
M(ㅁ) + u(어) + d(ㄷ)
➔ ㅁ+어+ㄷ = 머드!
Tub터브 (욕조)
⚙️ 기차 조립 공식
T(ㅌ) + u(어) + b(ㅂ)
➔ ㅌ+어+ㅂ = 터브!
