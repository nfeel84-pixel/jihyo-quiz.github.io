🔋 2일차: 소리에 생명을 불어넣는 '마법의 배터리 (모음)'

💡 왜 자음만 있으면 소리가 안 날까?

지효야, 1일차에 배운 자음 기차 칸 P(ㅍ)와 G(ㄱ)를 그냥 연결해 볼까?
"ㅍ...ㄱ... ㅍㄱ..." 쇳덩이가 부딪히는 소리만 나고 멋진 단어가 안 되지?

P (ㅍ)
+
⚡ I (이) ⚡
+
G (ㄱ)
=
피그! 🐷

바로 기차를 움직이게 하는 에너지 배터리가 빠졌기 때문이야!
영어에는 기차에 생명을 불어넣어 멋진 소리를 만들어주는 5개의 마법 배터리(A, E, I, O, U)가 있어.
오늘 이 5형제가 각각 어떤 소리 에너지를 가지고 있는지 알고리즘을 파헤쳐 보자!

⚡ A 배터리 ➔ '애' 소리 에너지를 뿜어!
Ant앤트 (개미)
⚙️ 조립 공식
A(애) + n(ㄴ) + t(트)
➔ 배터리가 맨 앞에 있네! "애-ㄴ-트"
Cat캣 (고양이)
⚙️ 조립 공식
C(ㅋ) + a(애) + t(ㅌ)
➔ 가운데서 에너지를 뿜어! "ㅋ+애+ㅌ = 캣"
Hat햇 (모자)
⚙️ 조립 공식
H(ㅎ) + a(애) + t(ㅌ)
➔ "ㅎ+애+ㅌ = 햇"
Bat뱃 (박쥐/방망이)
⚙️ 조립 공식
B(ㅂ) + a(애) + t(ㅌ)
➔ 1일차에 배운 B 머리칸 등장! "ㅂ+애+ㅌ = 뱃"
Apple애플 (사과)
⚙️ 조립 공식
A(애) + pple(플)
➔ pp처럼 두 개가 겹치면 하나로 합쳐서 발음해.
⚡ E 배터리 ➔ '에' 소리 에너지를 뿜어!
Egg에그 (달걀)
⚙️ 조립 공식
E(에) + gg(그)
➔ "에-그!"
Pen펜
⚙️ 조립 공식
P(ㅍ) + e(에) + n(ㄴ)
➔ "ㅍ+에+ㄴ = 펜"
Net넷 (그물)
⚙️ 조립 공식
N(ㄴ) + e(에) + t(ㅌ)
➔ "ㄴ+에+ㅌ = 넷"
Ten텐 (숫자 10)
⚙️ 조립 공식
T(ㅌ) + e(에) + n(ㄴ)
➔ 1일차 T 머리칸! "ㅌ+에+ㄴ = 텐"
Red레드 (빨간색)
⚙️ 조립 공식
R(ㄹ) + e(에) + d(ㄷ)
➔ "ㄹ+에+ㄷ = 레드"
⚡ I 배터리 ➔ '이' 소리 에너지를 뿜어!
Pig피그 (돼지)
⚙️ 조립 공식
P(ㅍ) + i(이) + g(그)
➔ "ㅍ+이+그 = 피그"
Pin핀 (압정)
⚙️ 조립 공식
P(ㅍ) + i(이) + n(ㄴ)
➔ "ㅍ+이+ㄴ = 핀"
Six식스 (숫자 6)
⚙️ 조립 공식
S(ㅅ) + i(이) + x(ㄱ스)
➔ 1일차 S! "ㅅ+이+ㄱ스 = 식스"
Lip립 (입술)
⚙️ 조립 공식
L(ㄹ) + i(이) + p(ㅍ)
➔ "ㄹ+이+ㅍ = 립"
Igloo이글루
⚙️ 조립 공식
I(이) + g(그) + loo(루)
➔ 이-글-루
⚡ O 배터리 ➔ '오' (또는 아) 소리 에너지!
Dog도그 (개)
⚙️ 조립 공식
D(ㄷ) + o(오) + g(그)
➔ "ㄷ+오+그 = 도그"
Fox폭스 (여우)
⚙️ 조립 공식
F(ㅍ) + o(오) + x(ㄱ스)
➔ "ㅍ+오+ㄱ스 = 폭스"
Box박스 (상자)
⚙️ 조립 공식
B(ㅂ) + o(아) + x(ㄱ스)
➔ o는 때때로 '아' 소리도 내요! "ㅂ+아+ㄱ스 = 박스"
Pot팟 (냄비)
⚙️ 조립 공식
P(ㅍ) + o(아) + t(ㅌ)
➔ "ㅍ+아+ㅌ = 팟"
Top탑 (팽이/꼭대기)
⚙️ 조립 공식
T(ㅌ) + o(아) + p(ㅍ)
➔ "ㅌ+아+ㅍ = 탑"
⚡ U 배터리 ➔ '어' 소리 에너지를 뿜어!
Sun썬 (태양)
⚙️ 조립 공식
S(ㅅ) + u(어) + n(ㄴ)
➔ "ㅅ+어+ㄴ = 썬"
Bug버그 (벌레)
⚙️ 조립 공식
B(ㅂ) + u(어) + g(그)
➔ 앗! 시스템 버그의 그 버그! "ㅂ+어+그 = 버그"
Cup컵
⚙️ 조립 공식
C(ㅋ) + u(어) + p(ㅍ)
➔ "ㅋ+어+ㅍ = 컵"
Bus버스
⚙️ 조립 공식
B(ㅂ) + u(어) + s(스)
➔ "ㅂ+어+스 = 버스"
Nut넛 (견과류)
⚙️ 조립 공식
N(ㄴ) + u(어) + t(ㅌ)
➔ "ㄴ+어+ㅌ = 넛"
