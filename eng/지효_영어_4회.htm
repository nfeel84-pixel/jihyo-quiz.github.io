🪄 4일차: 예외 처리! 마법의 요정 'Magic e'

💡 단어 끝에 'e'가 나타나면 마법이 시작돼!

지효야, 3일차에 배운 3칸 기차 C-A-P(캡) 기억나지?
그런데 이 기차 맨 뒤에 마법의 요정 'e'가 몰래 타면 엄청난 일이 발생해!

Cap
ㅋ+애+ㅍ =
캡 (모자)
➕ e ➔
Cape
ㅋ+에이+ㅍ =
케이프 (망토)
🧚‍♀️
나는 묵음!
마법만 걸어!

⚙️ Magic 'e' 실행 알고리즘:
1. 맨 끝에 있는 'e'는 입을 꾹 다물고 소리를 내지 않아. (묵음)
2. 대신, 앞에 있는 배터리(모음)에게 요술 지팡이를 얍! 하고 휘둘러서 "너의 원래 알파벳 이름대로 길게 소리 내!" 라고 마법을 걸어.

🪄 a_e 마법 ➔ '애'가 '에이'로 변신!
Cake케이크
⚙️ 마법 해독 공식
C(ㅋ) + a(에이) + k(ㅋ) + e(묵음)
➔ 캑(cak) ❌ / 케이크(cake) ⭕
Make메이크 (만들다)
⚙️ 마법 해독 공식
M(ㅁ) + a(에이) + k(ㅋ) + e(묵음)
➔ 맥(mak) ❌ / 메이크(make) ⭕
Gate게이트 (문)
⚙️ 마법 해독 공식
G(ㄱ) + a(에이) + t(ㅌ) + e(묵음)
➔ 갯(gat) ❌ / 게이트(gate) ⭕
🪄 i_e 마법 ➔ '이'가 '아이'로 변신!

P(ㅍ) + i(아이) + n(ㄴ) + e(묵음)
➔ 핀(pin) ❌ / 파인(pine) ⭕

B(ㅂ) + i(아이) + k(ㅋ) + e(묵음)
➔ 빅(bik) ❌ / 바이크(bike) ⭕
🪄 o_e 마법 ➔ '아/오'가 '오우'로 변신!
Rose로즈 (장미)
⚙️ 마법 해독 공식
R(ㄹ) + o(오우) + s(ㅈ) + e(묵음)
➔ s가 모음 사이에 끼면 'ㅈ' 소리가 나요.
Bone본 (뼈)
⚙️ 마법 해독 공식
B(ㅂ) + o(오우) + n(ㄴ) + e(묵음)
➔ ㅂ+오우+ㄴ = 본! (원어민은 보운! 에 가깝게 해요)
Note노트 (공책)
⚙️ 마법 해독 공식
N(ㄴ) + o(오우) + t(ㅌ) + e(묵음)
➔ 낫(not) ❌ / 노트(note) ⭕
🪄 u_e 마법 ➔ '어'가 '유'로 변신!
