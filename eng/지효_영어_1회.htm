🚀 1일차: 영어 기차의 '머리칸' 암호 풀기

💡 단어들은 어떻게 조립될까?

지효야, 단어 카드 안에 있는 [조립 공식]을 잘 살펴봐!
첫소리 자음(머리칸) 뒤에 어떤 소리들이 연결되어서 단어가 완성되는지 힌트가 적혀있어.
가끔은 글자 여러 개가 뭉쳐서 하나의 소리를 내는 '특수 덩어리'도 있으니 눈크게 뜨고 찾아보자!

M (엠) ➔ 머리칸 소리: 'ㅁ'
Melon 멜론
⚙️ 기차 조립 공식
M(ㅁ) + e(에) + l(ㄹ) + o(오) + n(ㄴ)
➔ 순서대로 이으면 "멜-론!"
Milk 밀크
⚙️ 기차 조립 공식
M(ㅁ) + i(이) + l(ㄹ) + k(ㅋ)
➔ 순서대로 이으면 "밀-크!"
Moon 문 (달)
⚙️ 기차 조립 공식
M(ㅁ) + oo(우) + n(ㄴ)
➔ o가 두 개 뭉치면 '우' 소리가 나요. "ㅁ+우+ㄴ = 문"
Mouse 마우스 (쥐)
⚙️ 기차 조립 공식
M(ㅁ) + ou(아우) + s(스) + e(소리안남)
➔ ou가 합체해서 '아우' 소리를 내는 특수 덩어리!
Monkey 몽키 (원숭이)
⚙️ 기차 조립 공식
Mon(몽) + key(키)
➔ 단어가 길 때는 반으로 뚝! 잘라서 두 번에 나눠 읽어요.
B (비) ➔ 머리칸 소리: 'ㅂ'
Bus 버스
⚙️ 기차 조립 공식
B(ㅂ) + u(어) + s(스)
➔ "ㅂ+어+스 = 버스!"
Bed 베드 (침대)
⚙️ 기차 조립 공식
B(ㅂ) + e(에) + d(ㄷ)
➔ "ㅂ+에+ㄷ = 베드!"
Book 북 (책)
⚙️ 기차 조립 공식
B(ㅂ) + oo(우) + k(ㅋ)
➔ Moon에서 본 oo(우) 덩어리가 또 나왔네! "ㅂ+우+ㅋ = 북"
