🚀 1일차: 영어 기차의 '머리칸' 암호 풀기

💡 단어들은 어떻게 조립될까?

지효야, 단어 카드 안에 있는 [기차 조립 공식]을 잘 살펴봐!
빨간색으로 표시된 머리칸(첫소리 자음) 뒤에 어떤 소리들이 연결되어서 단어가 완성되는지 힌트가 적혀있어.
소리를 직접 들어보면서, "아하! 이래서 이런 소리가 나는구나" 하고 알고리즘을 발견해 보자!

M (엠) ➔ 머리칸 소리: 'ㅁ'
Melon멜론
⚙️ 기차 조립 공식
M(ㅁ) + e(에) + l(ㄹ) + o(오) + n(ㄴ)
➔ 순서대로 이으면 "멜-론!"
Milk밀크 (우유)
⚙️ 기차 조립 공식
M(ㅁ) + i(이) + l(ㄹ) + k(ㅋ)
➔ 순서대로 이으면 "밀-크!"
Moon문 (달)
⚙️ 기차 조립 공식
M(ㅁ) + oo(우) + n(ㄴ)
➔ o가 두 개 뭉치면 '우' 소리!
Mouse마우스 (쥐)
⚙️ 기차 조립 공식
M(ㅁ) + ou(아우) + s(스) + e(묵음)
➔ ou는 합체해서 '아우' 특수 덩어리!
Monkey몽키 (원숭이)
⚙️ 기차 조립 공식
Mon(몽) + key(키)
➔ 긴 단어는 반으로 뚝! 잘라 읽기.
B (비) ➔ 머리칸 소리: 'ㅂ'
Bus버스
⚙️ 기차 조립 공식
B(ㅂ) + u(어) + s(스)
➔ "ㅂ+어+스 = 버스!"
Bed베드 (침대)
⚙️ 기차 조립 공식
B(ㅂ) + e(에) + d(ㄷ)
➔ "ㅂ+에+ㄷ = 베드!"
Book북 (책)
⚙️ 기차 조립 공식
B(ㅂ) + oo(우) + k(ㅋ)
➔ oo(우) 덩어리가 또 나왔네!
Bear베어 (곰)
⚙️ 기차 조립 공식
B(ㅂ) + ear(에어)
➔ ear는 한 번에 '에어' 소리를 내요.
Banana바나나
⚙️ 기차 조립 공식
Ba(바) + na(나) + na(나)
➔ 바-나-나 세 칸으로 연결된 기차!
D (디) ➔ 머리칸 소리: 'ㄷ'
Desk데스크 (책상)
⚙️ 기차 조립 공식
D(ㄷ) + e(에) + s(스) + k(크)
➔ "ㄷ+에+스+크 = 데스크"
Dog도그 (개)
⚙️ 기차 조립 공식
D(ㄷ) + o(오) + g(그)
➔ "ㄷ+오+그 = 도그"
Door도어 (문)
⚙️ 기차 조립 공식
D(ㄷ) + oor(오어)
➔ o 두 개에 r이 붙으면 '오어'
Duck덕 (오리)
⚙️ 기차 조립 공식
D(ㄷ) + u(어) + ck(ㅋ)
➔ c와 k가 뭉쳐서 하나의 'ㅋ' 소리!
Doll돌 (인형)
⚙️ 기차 조립 공식
D(ㄷ) + o(아/오) + ll(ㄹ)
➔ l이 두 개여도 하나처럼 발음해요.
P (피) ➔ 머리칸 소리: 'ㅍ'
Pig피그 (돼지)
⚙️ 기차 조립 공식
P(ㅍ) + i(이) + g(그)
➔ "ㅍ+이+그 = 피그"
Pen펜
⚙️ 기차 조립 공식
P(ㅍ) + e(에) + n(ㄴ)
➔ "ㅍ+에+ㄴ = 펜"
Pizza피자
⚙️ 기차 조립 공식
Pi(피) + zza(자)
➔ 두 덩어리로 잘라서 읽어요.
Pink핑크 (분홍)
⚙️ 기차 조립 공식
P(ㅍ) + i(이) + n(ㄴ) + k(크)
➔ "ㅍ+이+ㄴ+크 = 핑크"
Piano피아노
⚙️ 기차 조립 공식
Pi(피) + a(아) + no(노)
➔ 피-아-노 세 칸 기차!
S (에스) ➔ 머리칸 소리: 'ㅅ'
Sun썬 (태양)
⚙️ 기차 조립 공식
S(ㅅ) + u(어) + n(ㄴ)
➔ "ㅅ+어+ㄴ = 썬"
Star스타 (별)
⚙️ 기차 조립 공식
S(ㅅ) + t(ㅌ) + ar(아르)
➔ ar이 만나면 '아르' 소리가 나요.
Snake스네이크 (뱀)
⚙️ 기차 조립 공식
S(ㅅ) + n(ㄴ) + a(에이) + k(크) + e(묵음)
➔ 끝에 e가 오면 a가 '에이'로 변신! (4일차 예고)
Snow스노우 (눈)
⚙️ 기차 조립 공식
S(ㅅ) + n(ㄴ) + ow(오우)
➔ ow가 뭉쳐서 '오우' 소리를 내요.
Spider스파이더 (거미)
⚙️ 기차 조립 공식
Spi(스파이) + der(더)
➔ 길 때는 반으로 자르기!
T (티) ➔ 머리칸 소리: 'ㅌ'
Tent텐트
⚙️ 기차 조립 공식
T(ㅌ) + e(에) + n(ㄴ) + t(트)
➔ "ㅌ+에+ㄴ+트 = 텐트"
Tiger타이거 (호랑이)
⚙️ 기차 조립 공식
Ti(타이) + ger(거)
➔ 타-이-거 덩어리로 읽어요.
Tree트리 (나무)
⚙️ 기차 조립 공식
T(ㅌ) + r(ㄹ) + ee(이)
➔ e가 두 개면 길게 '이~'
Train트레인 (기차)
⚙️ 기차 조립 공식
T(ㅌ) + r(ㄹ) + ai(에이) + n(ㄴ)
➔ ai가 합체해서 '에이' 소리를 내요.
Taxi택시
⚙️ 기차 조립 공식
T(ㅌ) + a(애) + x(ㄱ스) + i(이)
➔ x는 특이하게 'ㄱ스' 두 가지 소리를 내요.
